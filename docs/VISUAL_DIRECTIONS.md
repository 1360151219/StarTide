## 方向判断

老板认可的是现有角色与怪物的可爱动漫资产，而不是旧界面的整套材质。正确改造方式是保留角色身份与玩法语法，重点统一自然场景、HUD 材质、信息层级、技能反馈和局外导航。

| 不变项 | 重点改造项 |
|---|---|
| 竖屏、俯视、自动攻击的 Vampire Survivors-like | 三生态背景的通透度与读战降噪 |
| 两名英雄与四类怪物的造型、比例、五官和标志性色块 | HUD、卡牌、按钮、Tooltip 的远征装备材质 |
| 3 个自动技能槽、三选一升级与现有内容结构 | 技能轮廓、命中峰值、受伤、拾取和稀有度反馈 |
| 稳定内容 ID、存档和战斗数值 | 字体、数字、间距、对齐和正式图标系统 |

## D「日光远征动画」：清透赛璐璐与自然冒险绘卷

### 1. 一句话视觉命题

把幸存者式混战装进阳光下的远征动画：可爱角色鲜明、自然地图通透、UI 像随队携带的轻便冒险装备。

### 2. 世界观气质

乐观但不幼稚的自然远征。平时清新、舒展、有空气感；危险出现时依靠珊瑚红、收束形状、局部降噪和短促动画收紧气氛，不依靠血腥、全屏变暗或持续发光。

### 3. 五个核心视觉关键词

- 清透赛璐璐
- 日光远征
- 自然手绘
- 轻量装备感
- 读战优先

### 4. 材质语言

- 浅色帆布：面板、HUD、选择卡和说明区。
- 桦木：边梁、地图支架和按钮结构。
- 搪瓷徽章：导航、选中、品质角部结构与功能图标底。
- 磨砂金属扣：连接点和少量关键装饰；单屏可见面积不超过 4%。
- 织带、绳结与少量旧地图纸：页签、路径、进度和 Tooltip。
- 不使用黑纸、舞台幕布、人偶关节、玻璃或写实塑料作为主材质。

### 5. 形状语言

- 角色与怪物保留圆润可爱的动漫轮廓；敌方危险额外使用向内收束、尖角或缺口。
- 面板使用轻微切角、织带标签和不对称挂扣；同页最多两种面板母形。
- 主按钮采用横向织带或轻切角木牌，次级按钮保持紧凑。
- 穿透与高伤技能偏尖锐，范围与治疗偏圆润，持续技能使用可追踪弧线或离散轨道。
- 选中、稀有和危险同时使用颜色与形状信号，不只换描边颜色。

### 6. 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| Background | `#DDEFE7` | 晨雾、局外底色与留白 |
| Surface | `#FFF6E2` | 帆布面板与 Tooltip |
| Primary Text | `#243C43` | 正文、数字、轮廓和主结构 |
| Secondary Text | `#5C7073` | 说明、单位和弱信息 |
| 主色 | `#4FA7B5` | 导航、友方、选中和主结构 |
| 辅助色 | `#76B77A` | 生态、恢复和路径 |
| 强调色 | `#F2B84B` | 每屏唯一主操作与最高价值 |
| 危险色 | `#E45B5B` | 敌方预警、玩家受伤与失败 |

生态色只进入场景与内容插画，不能自行成为新的 UI 语义色。

### 7. 字体方向

- 仪式性展示标题：`NotoSerifSC-UI.otf`，仅用于胜利、章节和短标题。
- 远征页面、关卡名、主操作和短属性标题：`SmileySans-Oblique.otf`，18 px 以下不得使用。
- 正文、说明、字段名和数字：`NotoSansSC-Regular.otf`；关键数字仍使用固定宽容器，不随展示字体倾斜。
- 战斗数字使用粗字重、固定宽容器与等宽数字特性。
- 最小功能字号 14 px；文字、数字和品质不烘焙进图片。

### 8. UI 边框设计

深湖墨细描边、帆布内层、单侧织带或搪瓷扣。主面板允许两个角出现 8～12 px 缺口，四角不得复制同一装饰；战斗 HUD 尽量共享边界，避免每个数值各套一张卡。

### 9. 装备稀有度表现

| 品质 | 颜色与结构 | 左上角识别 | 揭示反馈 |
|---|---|---|---|
| 普通 | 灰色帆布 `#C9CDCA` 与单层压线 | 无附加徽记 | 静态落位 |
| 稀有 | 鲜绿搪瓷 `#42B873` 与双层压线 | 单个非对称缺口 | 一次短扫光与双音 |
| 顶级 | 明亮金色 `#F2B84B` 与三段阶梯边框 | 单个冠形或日轮形徽记 | 徽记弹入一次与三音上行 |

三档均使用近直角 `1:1` 正方形，品质结构收在方格与左上角内，不增加底部节点、挂扣或吊坠。颜色不是唯一信号；关闭颜色后仍应可区分三档。已装备物品只在右上角叠加与英雄切换组件同源的小号角色头像。

### 10. 战斗背景方向

保持开放、可滚动的俯视自然地图，不绘制可见竞技场边界。玩家附近约 180 px 降低 15%～20% 纹理对比和装饰密度；装饰以 3～5 个成簇出现，不均匀平铺。

- 风铃草原：草浪、铃花、浅水洼和风车影。
- 黄金绿洲：暖沙丘、青绿水脉、旅行旗和耐旱植物。
- 水晶火山：炭灰岩板、低亮裂隙和蓝绿晶体，保持空气感。

### 11. 按钮、面板与 Tooltip

- 按钮：横向织带或轻切角木牌；每页只有一个日照金主按钮。
- 面板：暖象牙帆布底、轻木支撑和一个身份标签，不使用白色网页卡片阵列。
- Tooltip：窄地图签配指向缺口，深色正文，最多三行，不遮挡目标或越过安全区。

### 12. 状态图标风格

两至三色赛璐璐象形、深湖墨外轮廓、明确负形。主体占图标面积 65% 以上，20 px 灰度下仍可辨识；Buff 向外展开、Debuff 向内收束、Healing 环抱向上、Block 使用闭合盾形。禁止 Emoji 和 Unicode 符号充当正式图标。

### 13. 技能打出与命中动画

统一为“蓄势色块 → 明确轨迹 → 命中单次峰值 → 少量属性粒子收尾”。普通施放 100～200 ms，命中峰值 35～70 ms，收尾 140～280 ms；同屏持续循环高亮不超过两组，不用全局时间缩放制造冲击。

### 14. 明确禁止的设计模式

- 剪纸影戏、人偶关节、暗色剧场幕布和彩窗主导画面。
- SaaS 后台、白色卡片海、通用网页按钮和统一大圆角。
- 玻璃拟态、紫色科技渐变、满屏发光与无语义光晕。
- 写实 3D 塑料、照片级背景或不同 AI 渲染风格混用。
- 改变现有角色比例、五官、武器和标志性色块。
- 只换颜色、不换轮廓的技能、状态和稀有度。
- 用 Emoji 代替正式游戏图标。
- 生成带文字、数字、按钮或品质标签的卡牌图片。
- 封闭竞技场、手动攻击按钮、技能按键或卡牌出牌区。

### 15. 参考方向

- 《二之国》：参考自然氛围与冒险空气感。
- 《World Flipper》《Dragalia Lost》：参考动漫战斗辨识与短促反馈。
- 《碧蓝幻想》：参考材质层级和品质结构。
- 《宝可梦不可思议迷宫 DX》：参考冒险地图气质。
- 现实中的帆布地图袋、桦木工具、搪瓷徽章与旅行标签：参考材质逻辑。

只参考设计方法，不复制任何现成角色、UI、构图、纹样或素材。
