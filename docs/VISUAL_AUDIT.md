# 《星潮守望者》视觉审计与整改复验

> 视觉方向：D「日光远征动画」
> 首页设计：已定稿（painted 远征地图 + 罗盘挂旗 + 织带旗导航 + 帆布信息牌 + 罗盘帆船主按钮）
> 本轮专项：以已完成的首页画风为基准，审计「角色」页面
> 审计日期：2026-08-10
> 验收画布：540×960、540×1170、540×1200、720×960
>
> 说明：项目此前的全流程整改复验（战斗、三选一、结算、HUD、音频等 10 项 P0–P2）已闭环，记录保留在 Git 历史，不在此重复。本文件现聚焦「角色」页面与定稿首页之间的画风一致性问题，作为唯一视觉审计来源直接维护。

## 1. 审计范围与方法

- 基准：以定稿首页 `preview/start.png` 的画风与材质为对照标准。
- 对象：角色页三个分区——状态、装备、技能，运行截图为 `preview/hero_equipment.png`、`preview/hero_selection.png`、`preview/hero_training.png`。
- 依据：`ART_DIRECTION.md`（材质、形状、颜色、字体、保留项）、`UI_SPEC.md`（第 9 节角色/装备/训练、第 12–14 节组件与图标）、`ASSET_MANIFEST.md`（素材边界）。
- 方法：对照代码实现与实际渲染，按 11 个维度逐项判断，不修改任何玩法、数值、内容 ID、存档、音频 Cue 或按钮行为。
- 结论定位：角色页「骨架与功能成立、动画反馈到位」，但**画风层级明显落后于定稿首页**，核心矛盾是「首页 painted 世界」与「角色页平涂奶油面板」两套语言直接对撞。

## 2. 与首页的画风基准差异（总纲）

首页的成片感来自三件事：一张 painted 远征地图承载环境、一组 painted 专属 UI 素材（罗盘挂旗 / 织带旗 / 帆布信息牌 / 罗盘帆船钮）、以及英雄站在地图上形成的唯一焦点。角色页把这三点几乎全部丢失：

| 观察点 | 首页（定稿） | 角色页（现状） | 判断 |
|---|---|---|---|
| 背景 | painted 远征地图，统一提亮降饱和 | **同一张 painted 地图仍显示在角色页身后**（未隐藏），且装备页额外再画一套程序卷层丘陵 | 两套环境语言对撞 |
| UI 材质 | painted 专属素材（挂旗、织带旗、信息牌、罗盘钮） | 全部为程序 `StyleBoxFlat` 奶油圆角面板 + 细描边 | 保真度断层 |
| 主标题字体 | Smiley Sans（`apply_level_title`） | 全页 Noto Sans（`surface_label`），无展示字体层 | 字体层缺失 |
| 焦点 | 英雄立于地图，焦点唯一 | 英雄夹在 painted 背景与平涂面板之间，与金色战力数字争焦点 | 焦点浑浊 |
| 导航 | 自由织带旗（宽窄错落、挂旗形态） | 三排等宽分段按钮竖向堆叠 | 明显网页 Tab 感 |

**根因（可回溯到运行时）**：`frontend_shell.gd` 的 `_show_page()` 只切换 `lobby_view.visible`，从未隐藏 `start_screen.gd` 建立的 `screen_background`（首页 painted 地图 TextureRect）。因此角色页顶部（约 0–88 px）、底部（约 772–840 px）、左右边（painted 藤蔓木框）以及半透明的英雄切换条（`SURFACE_ALT` @0.72）都在漏出首页地图，形成「UI 贴在壁纸上」的观感——这正是首页整改时消除过的「手机壁纸嵌入感」，在角色页重新出现。

## 3. 分维度审计

| 维度 | 判断 | 结论摘要 |
|---|---|---|
| 视觉层级 | 部分不通过 | 英雄未成为唯一一级焦点；金色战力数字与英雄争焦点；背景地图抢注意力 |
| 信息可读性 | 部分通过 | 功能字号≥14 px、数字右对齐达标；但半透明面板叠 painted 背景处对比不足 |
| 美术风格一致性 | 不通过 | painted 地图 + 程序卷层丘陵 + 平涂奶油面板三套语言同屏 |
| 角色辨识度 | 通过 | 两名英雄完整 Q 版渲染、帽型发色可区分，保留达标 |
| 装备辨识度 | 部分通过 | 品质靠边框层数/挂扣表达成立；但普通件呈灰白网格、图标偏小 |
| 技能辨识度 | 部分通过（受限） | 训练行过平、列表感强；当前多为未发现态，图标辨识待有内容时复验 |
| UI 材质与形状 | 不通过 | 未复用首页 painted 素材，全程序细描边奶油面板，材质保真度低于首页 |
| 字体与数字系统 | 部分通过 | 数字规范达标；但全页缺失 Smiley Sans 展示层，标题与首页不一致 |
| 色彩系统 | 部分通过 | 令牌基本合规；普通=灰、稀有=冷白底、战力下降用 Danger 红有语义偏移 |
| 间距与对齐 | 部分通过 | 4 px 网格与右对齐达标；但顶部约 198 px 被三段导航吃掉，双排页签贴太近 |
| 动画反馈 | 通过 | 分区滑入、战力滚动+弹跳+增减浮标、点击互动均成立，是相对亮点 |
| 游戏氛围 | 不通过 | 平涂面板覆盖约 3/4 屏，冲淡首页 painted 远征氛围，像盖在壁纸上的设置层 |
| 网页模板感 | 偏高 | 三排等宽页签 + 奶油圆角面板 + 四列网格 + 下边框列表行，整体像移动端后台 |
| AI 生成感 | 偏中 | painted 地图与程序卷层两套渲染拼贴同屏，触碰「混用不同渲染风格」红线 |

### 3.1 视觉层级

- 现状：装备页第一眼最亮的是大块奶油面板与金色「战力 1000」，英雄立绘尺寸中等且被夹在 painted 背景（火山、亮天空）与前景面板之间。
- 问题：ART_DIRECTION 要求「角色 > 装饰」，UI_SPEC §9 要求「选中后角色台和属性同时更新、角色为焦点」。当前英雄既要对抗身后高饱和 painted 地图，又要对抗身前平涂面板，焦点被稀释；金色战力数字（Accent）与英雄并列争第一焦点。
- 建议：压暗/虚化背景（见 3.3），把英雄舞台做成明确的一级焦点区；战力数字保持 Accent 但收敛尺寸或降低其与英雄的对比竞争，确保「先看到英雄，再看到战力」。

### 3.2 信息可读性

- 现状：功能字号均 ≥14 px，核心属性「字段名左对齐 / 数字右对齐」达标（`character_status_panel.gd`），`LV.N`、`I/II/MAX`、百分比格式统一。
- 问题：英雄切换条 `SURFACE_ALT@0.72`、核心属性内衬 `SURFACE_ALT@0.76`、战力构成内衬 `SURFACE@0.72` 等多处半透明面板，叠在漏出的 painted 地图或彼此之上，降低了文字与底的对比稳定性；顶部/底部直接压在 painted 地图上的文字（如页签文案）缺少实色底签保护。
- 建议：凡承载文字的面板统一改为不透明实色底或加实色底签（呼应 ART_DIRECTION「文字落在场景上时使用实色底签或局部压暗」）；不要让关键文字区透出高频 painted 背景。

### 3.3 美术风格一致性（最严重）

- 现状：同屏三套渲染语言——① 身后 painted 远征地图（`screen_background` 未隐藏）；② 装备页英雄台内 `character_stage_backdrop.gd` 程序绘制的赛璐璐渐变天空 + 两层丘陵 + 散点树丛 + 白色椭圆台；③ 全页平涂奶油 `StyleBoxFlat` 面板。
- 问题：直接违反「禁止混用不同 AI 渲染风格」「静态背景只承载环境、可交互内容由 Godot 绘制」的边界；painted 地图与程序卷层丘陵的笔触、光影、饱和度完全不同，拼贴痕迹明显。这是角色页与首页画风差距的最大来源。
- 建议（择一并保持单一环境语言）：
  - 方案 A：隐藏/替换首页地图，给角色页一个**统一的低对比生态 + 浅木支架**背景（UI_SPEC §9 原意），并**移除**装备页内的程序卷层丘陵，让英雄台直接坐落在该统一背景上；
  - 方案 B：保留一张背景，但对其做强提亮 + 强降饱和 + 轻虚化，使之成为真正的 L0 环境层，同样移除第二套程序丘陵。
  - 两方案都必须做到「整页只有一套环境渲染」。

### 3.4 角色辨识度、装备辨识度、技能辨识度

- 角色（通过）：`equipment_hero_stage.gd` 加载 `hero_rig_2d`，星潮守望者与烬羽游侠均为完整 Q 版立绘，帽型/发色/主体色块可区分，头身比与五官保留达标；点击有 `react()` 动作反馈。
- 装备（部分通过）：品质通过 `apply_quality_structure` 的边框层数 + `SunlitFrame` 挂扣数量表达，稀有/顶级结构可辨，符合「关闭颜色仍可区分」；但——
  - 普通件背景 `COMMON_BACKGROUND #f2f1e7` 偏灰白、普通描边色 `COMMON #8a9995` 与 `DISABLED` 同值，导致满背包普通装备呈「灰白网格」，既像卡片海又像禁用态；
  - 图标 48×40 置于 108×88 卡内，四周奶油留白偏多，主体占比偏低（ART_DIRECTION 期望主体占比高、20 px 灰度可辨）。
- 技能（部分通过、受限）：训练行用 `apply_training_row`（`SURFACE_ALT@0.34` + 1 px 下边框）呈现，三行近乎纯平列表，是全页最「后台表单」的区域；当前截图三项均为「未发现技艺 + 锁徽章」，技能图标本体辨识度需在有已发现内容时复验。锁徽章 + 名称 + 说明的结构本身清晰。
- 建议：普通品质底色回到暖象牙系并与禁用灰拉开；适当放大装备图标主体占比；技能行增加轻结构（分区块、图标底搪瓷片）替代纯下边框列表。

### 3.5 UI 材质和形状语言

- 现状：角色页完全不使用 `ASSET_MANIFEST.md` 中登记的任何 painted UI 素材（挂旗、织带旗、信息牌、罗盘钮均为首页专属），仅靠 `SunlitFrame` 程序切角/织带/挂扣 + `StyleBoxFlat` 奶油底表达材质。
- 问题：首页用 painted 素材兑现了「随队携带的帆布地图袋、桦木支架、搪瓷徽章」的材质承诺，角色页只有很薄的程序描边，材质保真度断层；大量统一奶油圆角矩形叠加，形状语言单一，缺少首页那种挂旗/织带的形态错落。
- 建议：为角色页引入至少一件与首页同级的 painted 身份构件（例如英雄身份挂旗 / 帆布营地支架），呼应首页罗盘挂旗；面板母形控制在两种以内但要与首页材质同源，减少「同一奶油圆角复制多次」。

### 3.6 字体和数字系统

- 现状：数字系统达标——战力用 `apply_power_label`（30 px 固定容器）、等级 `LV.N`、技能等级 `I/II/MAX`、百分比 `+X%` 均规范。
- 问题：**全页没有任何 Smiley Sans 展示字体**。英雄名（26 px）、「核心属性/战力构成/技能培养/装备背包」等短标题（16–20 px）全部走 `surface_label` → Noto Sans。而首页的关卡名用 `apply_level_title`（Smiley Sans）。按 ART_DIRECTION，页面标题、关卡名与 18–24 px 短属性标题应属 Expedition Heading / Key Label（Smiley Sans）。缺失该层使角色页更平、更像通用表单，与首页标题气质不一致。
- 建议：英雄名与各分区短标题改用 `UiFactory.apply_key_heading` / `apply_level_title`（Smiley Sans），正文与数字维持 Noto Sans；注意 18 px 以下回退 Noto，不模拟粗体。

### 3.7 色彩系统

- 现状：面板 `SURFACE/SURFACE_ALT`、边框 `PRIMARY`、选中 `PRIMARY_DARK` + 象牙字、战力 `ACCENT_DARK` 均在令牌内。
- 问题：
  - 稀有底 `RARE_BACKGROUND #e7edf6` 为冷调近白，叠加普通件灰白底，整体推高「白卡」观感；
  - 普通色与 `DISABLED` 同值（见 3.4）；
  - 切换英雄时战力下降用 `POWER_LOSS = DANGER` 红（截图「↓ 战力 -266」）。ART_DIRECTION 明确「Danger 只表达真实危险，不能用于无危险含义」，战力对比下降属于中性数值变化，不是危险。
- 建议：品质底色统一到暖象牙色阶、仅靠结构与徽章区分；战力下降改用中性/次级色（如 `MUTED_INK` 或 `SECONDARY`）而非 Danger 红，Danger 仅保留给真实危险。

### 3.8 间距和对齐

- 现状：面板统一 `x=18 / w=504`，4 px 网格与阶梯基本遵守，属性区右对齐达标。
- 问题：顶部约 198 px（英雄切换条 y=88 + 分区页签 y=142 + 面板 y=198）几乎全被导航 chrome 占用；英雄切换条与分区页签仅约 8 px 间隔，两排等宽条贴得过近，强化「双层 Tab」印象；装备页再叠一排四列筛选页签，形成竖向三排等宽页签。
- 建议：压缩顶部导航垂直预算，拉开或合并两排页签；把等宽分段替换为宽窄错落的织带索引（见 3.11），把省出的垂直空间还给英雄舞台。

### 3.9 动画反馈（相对亮点）

- 现状：分区切换 0.2 s 上移 + 淡入（CONTROL/PANEL 令牌）；战力变化 count-up + 面板弹跳 + 增减浮标上浮消隐（`equipment_hero_stage.gd`）；点击英雄 `react()`；页签按压有下沉态。节奏与 UI_SPEC §13 令牌一致，起势—峰值—收尾清晰。
- 问题：基本无。仅提示战力增减浮标当前借用 Danger 红表达下降，属色彩语义问题（见 3.7），非动画问题。
- 建议：保留现有动画设计；随色彩修正同步把下降浮标改为中性色。

### 3.10 游戏氛围

- 现状：平涂奶油面板覆盖约 3/4 屏，压在 painted 地图之上；装备页内又是一小块程序卷层丘陵。
- 问题：首页「阳光下的连续远征」氛围被大块平涂 UI 切断，程序丘陵在 painted 地图旁显得玩具化；整页更像「盖在首页壁纸上的设置面板」，而不是一处被设计过的「英雄营地 / 远征帐篷」空间。
- 建议：随 3.3 统一环境后，把角色页当作一个有场所感的营地来经营（英雄 + 支架 + 身份挂旗 + 低对比生态），让氛围与首页连续。

### 3.11 是否存在明显的「网页模板感」或「AI 生成感」

- 网页模板感（偏高）：三排等宽分段页签竖向堆叠、统一奶油圆角面板、四列装备网格、下边框分隔的列表行、右对齐数字列——组合起来仍是典型移动端后台/背包界面。首页整改时降下去的「等宽页签」在角色页不降反增（装备页达三排）。
- AI 生成感（偏中）：painted 地图与程序卷层丘陵两套渲染拼贴同屏，触碰「禁止混用不同 AI/渲染风格」。painted 地图本身是合规首页素材，问题在于它被当作与角色页无关的静态壁纸 + 第二套程序环境并置。
- 建议：统一为单一环境渲染（3.3）+ 织带索引替代等宽页签（3.8）+ 引入 painted 身份构件（3.5），三项落地后网页模板感与拼贴感可回到「不高于 2/5」。

## 4. 问题优先级汇总

| 优先级 | 问题 | 维度 | 建议动作 |
|---|---|---|---|
| P0 | 首页 painted 地图仍显示在角色页身后（`screen_background` 未隐藏），且装备页再画第二套程序环境 | 美术一致性、氛围、AI 感 | 统一为单一环境渲染：隐藏/替换首页地图并移除程序丘陵，或强降处理后仅保留一张 |
| P1 | 全页缺失 Smiley Sans 展示字体，标题气质与首页不一致 | 字体系统 | 英雄名与分区标题改用 Expedition Heading / Key Label |
| P1 | 未复用任何 painted UI 素材，材质保真度低于首页 | 材质与形状 | 引入至少一件与首页同源的 painted 身份构件 |
| P1 | 三排等宽页签竖向堆叠，网页模板感偏高 | 间距对齐、模板感 | 改为宽窄错落的织带索引，压缩顶部导航预算 |
| P1 | 承载文字的半透明面板叠 painted 背景，对比不稳 | 可读性 | 文字面板改不透明实色底或加实色底签 |
| P2 | 普通品质=灰白且与 DISABLED 同值、稀有底冷白，推高白卡感 | 色彩、装备辨识 | 品质底色回暖象牙、与禁用灰拉开，仅靠结构区分 |
| P2 | 战力下降用 Danger 红 | 色彩语义 | 改中性/次级色，Danger 仅留给真实危险 |
| P2 | 装备图标主体占比偏低、训练行过平 | 装备/技能辨识 | 放大图标主体、训练行加轻结构 |

## 5. 当前值得保留的部分

- 两名英雄的完整 Q 版立绘、头身比、五官、武器轴与标志性色块（`equipment_hero_stage.gd` + HeroRig）。
- 数字系统：战力固定宽容器、`LV.N`、`I/II/MAX`、百分比格式统一。
