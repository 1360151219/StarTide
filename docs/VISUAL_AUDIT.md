# 《星潮守望者》战斗界面视觉审计

> 视觉方向：D「日光远征动画」
> 审计日期：2026-08-12
> 审计对象：当前游戏战斗主界面及战斗内升级、暂停、精英、Boss、胜利揭示
> 实机画布：540×960、540×1170、540×1200、720×960
> 本轮性质：只读视觉审计；未修改游戏代码、逻辑、数值、内容 ID、存档、资源或音频 Cue

> 实施进度（2026-08-12）：已完成 #1、#2、#3、#6、#7、#8、#9、#10 的首轮实现；#4 已完成运行时统一色阶与局部降噪；#5 按实机反馈移除怪物、拾取物的运行时黑色闭合描边，素材本体仍待后续逐张审校。霜潮脉冲已恢复 360°结算与分段冰晶潮环。审计结论保留为修改前基线。

## 1. 结论

当前战斗已经具备可玩的完整视觉闭环：玩家、普通敌人、Boss 预警、伤害数字、受伤边缘、生命缺口、拾取去向、三技能槽、升级、暂停和胜利均能在真实主场景中出现。Boss 的直线、环形扇区和圆形落点预警，以及玩家受伤的方向红边、受击姿态和生命条缺口，是本轮最成熟的部分。

但画面尚未达到「日光远征动画」的统一成片度。最明显的矛盾不是功能缺失，而是三套视觉语法同时存在：高频生成感地表、不同批次的怪物插画，以及偏程序组件库的 HUD。常态战斗能读懂，技能密集、拾取和多目标受击同时发生时，玩家、掉落与敌方危险会争夺同一层级；暂停和升级又回到大面积白卡与规则圆角，形成明显的网页模板断层。

综合判断：

- 战斗玩法辨识：通过，3 秒内可以判断为竖屏、俯视、自动攻击的幸存者式战斗。
- 玩家与 Boss 危险辨识：基本通过；技能密集时玩家主体会被持续环和宽幅波前覆盖。
- 普通敌人与拾取物辨识：部分通过；怪物轮廓清楚，但素材渲染族不统一，拾取反馈在特效中偏弱。
- 技能辨识：部分通过；场上轮廓有区分，HUD 图标却统一为细节密集的圆形徽章，二者映射不够直接。
- 网页模板感：战斗主界面 `2.5/5`，战斗内升级与暂停 `3.5/5`；主要来自进度步进器、卡中套卡和大圆角按钮。
- 明显 AI / 拼贴感：`3/5`；主要来自五张地表的笔触、细节频率和光照不一致，以及旧怪物、新云林怪物和 Boss 的描边与内部细节不统一。

## 2. 审计方法与边界

- 实际运行 `main.tscn`，以固定 60 FPS 采集 50 张运行时画面，不使用编辑器静态预览代替实机结果。
- 覆盖开场横幅、首次移动、常态混战、星潮守望者三技能同时释放、敌人受击、三类拾取、玩家受伤、升级、暂停、精英、驺吾三种预警与执行、胜利早期 / 中期 / 完整揭示。
- 覆盖风铃草原、黄金绿洲、水晶火山、五色云林、千里云庭五个生态，并检查 540×960、540×1170、540×1200、720×960 四档画布。
- 使用隔离运行时档案构造满技能、Boss 和掉落状态；未写入正式存档，也未改变任何玩法数据文件。
- 以 200 ms 首读、最小功能字号 14 px、触控区 48×48 px、常态 HUD 遮挡预算 15%、角色周围低噪声区和灰度轮廓为判断基准。
- 本轮只评价视觉。音频内容、输入手感、设备性能和数值平衡不在结论范围内。

## 5. 当前值得保留的部分

- 两名英雄的头身比、五官、武器比例、主色和 HeroRig 动作；四档画布中均能保持身份。
- Boss 三类预警：冲刺通道、270° 尾扫与圆形流痕在颜色、轮廓和运动方向上均不同，尾扫保留了明确安全缺口。
- 玩家受伤反馈：来源方向红边、受击姿态、`-N` 数字、生命条缺口和受控震动形成完整因果链。
- 敌人受击的短内闪、来源方向位移、属性碎片和 120 ms 数字合并基础。
- 星芒枪、日轮守卫、霜潮脉冲在场上的直线、离散轨道与 360°破口冰环轮廓；问题主要在遮挡与 HUD 映射，不需要推翻技能身份。
- 强敌条替换普通状态条而不是继续向下叠加，保持了顶部高度预算。
- Danger、Healing、Primary、Accent 的主要语义没有互换；危险红没有被普通按钮或品质滥用。
- `LV.N`、`MM:SS`、生命值、击败数和罗马技能等级的基础格式，以及伤害数字的固定字形与阴影。
- 五生态的主题差异和开放地图结构；没有可见竞技场边界，也没有使用暗幕营造难度。
- 540×960、540×1170、540×1200、720×960 下的安全区与锚点；HUD 未裁切，长屏只延展战场，宽屏保持设计框居中。
- 胜利时英雄切换到独立庆祝姿态，战场被压暗但仍保留环境上下文，主操作使用唯一日照金。

## 6. 建议修改顺序与验收条件

1. `P0` 首轮已落地：摇杆改为任意战场触点唤出并在松手后 160 ms 隐去；拾取主体加入 34 px 最小隔离底，吸附阶段提层并使用 4 px 弧形尾迹，HUD 目标只闪一次；日轮持续层已放到角色后方并降 Alpha，玩家伤害数字移至来源反侧。移动、拾取和技能结算保持不变。
2. 地表已通过共享运行时色阶和高频生态轻量软化完成第一轮收敛；怪物与拾取物不再额外叠加运行时黑色闭合描边，保留素材细节、接地阴影和受击内闪。下一步只剩火山、云林、云庭与敌人的素材本体审校，不改变角色、怪物和技能内容 ID。
3. 普通敌人血条已改为受击后 700 ms 短显；升级与暂停减少卡中套卡，远征进度改为绳路与异形节点；Boss 阶段刻度跨段时单次脉冲。后续继续做素材级精修，不新增平行组件或第三套视觉语言。

下一轮至少满足：

- 10% 尺寸下仍能先区分玩家、敌人、危险、拾取物四类；云林敌人不被误判为友方。
- 满技能混战中，玩家面部、武器轴和敌方预警不存在持续遮挡；同屏常亮循环仍不超过两组。
- 拾取物从出现、牵引到 HUD 目标三段都可追踪，且不会延迟真实拾取结算。
- 常态不透明 HUD 面积不超过 15%，强敌阶段不超过 20%；状态条与强敌条继续互斥。
- 圆形技能入口不会被理解为施放按钮；展开明细后三项技能在 20 px 灰度下仍可凭轮廓区分，空槽不会被理解为资源缺失。
- 五生态的平均曝光、角色脚下对比和敌人接地阴影进入同一视觉范围；网页模板感与明显拼贴感均降至 `2/5` 以下。
