# 《星潮守望者》方案 D UI 规范

> 方向：日光远征动画  
> 基准画布：540×960，竖屏  
> 视觉母版：[ART_DIRECTION.md](./ART_DIRECTION.md)  
> 实现参考：[战斗](./references/battle-reference.png) · [三选一](./references/reward-reference.png) · [远征地图](./references/map-reference.png)

本规范只改变现有玩法之上的界面表现，不新增交互、技能槽、奖励项或战斗操作。坐标均为 540×960 逻辑像素的目标值；实现必须由 Safe Area、锚点和当前响应式布局驱动。

## 1. 全局系统

### 1.1 网格与间距

- 基础网格：4 px。
- 间距阶梯：4、8、12、16、24、32、48 px。
- 基准安全内容区：`x = 18…522`，顶部和底部叠加系统 Safe Area。
- 页面主内容宽 504 px；模态宽 480 px；窄文本列 432 px。
- 最小触控区 48×48 px；主按钮高 60～68 px；次级按钮高 48～56 px。
- 内容内边距：小组件 8 px、卡片 12 px、面板 16 px、主模态 24 px。
- 文字距结构边、压线和扣件至少 12 px；24～32 px 小图标与文字保持 8 px 间距。
- 属性字段名左对齐，数字使用固定宽列右对齐；禁止用空格拼接对齐，禁止文字越过容器或被边框裁切。

### 1.2 颜色令牌

| Token | 色值 | 用途 |
|---|---|---|
| `BACKGROUND` | `#DDEFE7` | 局外底色与雾气 |
| `SURFACE` | `#FFF6E2` | 主帆布面板 |
| `SURFACE_ALT` | `#EAF4E8` | 次级区、空槽、友方弱层级 |
| `INK` | `#243C43` | 正文、数字、轮廓 |
| `MUTED_INK` | `#5C7073` | 次级说明 |
| `PRIMARY` | `#4FA7B5` | 导航、选中、友方结构 |
| `SUPPORTING` | `#76B77A` | 生态、恢复、路径 |
| `ACCENT` | `#F2B84B` | 唯一主操作与最高价值 |
| `DANGER` | `#E45B5B` | 敌方危险与玩家受伤 |
| `HEALING` | `#58B985` | 治疗与恢复 |
| `BLOCK` | `#6E91B3` | 护盾与格挡 |
| `RARE` | `#6C86C8` | 稀有搪瓷内衬 |

页面不得直接创建新的全局颜色。生态颜色只能进入场景与内容插画，不成为新 UI 语义色。

### 1.3 信息层级

| 层级 | 内容 | 规则 |
|---|---|---|
| L0 | 地面、远景、低对比装饰 | 不承担交互，不与危险同色同形 |
| L1 | 玩家、敌人、拾取物 | 保证轮廓分离，玩家为局部最高识别点 |
| L2 | 技能、预警、命中特效 | 预警优先于友方装饰，命中只短时超过单位 |
| L3 | 伤害数字、拾取去向、状态反馈 | 短时显示，不形成文字云 |
| L4 | 常态 HUD、摇杆、自动技能槽 | 总面积受控，不遮挡中心战场 |
| L5 | 暂停、升级、结算、Tooltip | 冻结并弱化战场 |
| L6 | 受伤边缘闪、升级揭示、胜利强调 | 单次短反馈，不持续占用 |

### 1.4 遮挡预算

- 常态战斗不透明 HUD 面积不超过 15%。
- 精英阶段不透明 HUD 面积不超过 20%；精英条替换状态条，不向下叠加。
- 玩家周围约 180 px 是动态低噪声区；装饰与持续粒子不得长期停留。
- 战斗不得出现前景画框、幕布或可见竞技场边界。

## 2. 响应式与安全区

| 画面比例 | 策略 |
|---|---|
| 3:4～16:9 | 保持 HUD 和触控尺寸，压缩上下留白 |
| 9:16 | 540×960 设计基准 |
| 19.5:9～20:9 | 战场上下延伸，组件贴 Safe Area，不拉伸纹理 |

- 顶部 HUD 锚定 Safe Area 顶部；摇杆与技能槽锚定底部。
- 中央战场和覆盖层使用 540×960 等比设计框居中，额外区域只用于环境延伸。
- 空间不足时按“去装饰 → 缩间距 → 缩非关键文字”处理；功能字号不得低于 14 px。

## 3. 战斗主界面

### 3.1 目标布局

| 区域 | 基准矩形 | 内容 |
|---|---|---|
| 顶部 HUD | `x18 y8 w504 h72` | 等级、生命、时间、击败、暂停 |
| 状态条 | `x18 y86 w504 h44` | 关卡、被动、限时状态 |
| 精英条 | `x96 y86 w348 h44` | 精英名、生命、最多 2 状态；替换状态条 |
| 战斗主区 | `x0 y136 w540 h654` | 玩家、敌人、技能、拾取物、预警 |
| 摇杆 | 视觉直径 142，中心约 `x108 y830` | 唯一常驻操作件 |
| 自动技能槽 | `x236 y830 w286 h88` | 正好 3 个自动槽，不可点击 |

### 3.2 顶部 HUD

- 外形为连续帆布信息条：深湖墨结构边、暖象牙承载面、左侧晨湖青等级标签、右侧独立暂停搪瓷钮。
- 第一层显示 `LV.8`、`06:42`、击败图标与数字；数字使用固定宽容器。
- 生命条高 14～16 px，生命数字可置于条内；经验条高 6～8 px，位于最底部。
- 生命低于 30% 时只切换生命条、数字和一个缺口为 Danger；整个 HUD 不红色脉冲。
- 暂停按钮 48×48 px，使用正式双竖线图形，不使用 Emoji。

### 3.3 状态与精英信息

- 普通怪物不显示姓名、技能卡或常驻血条。
- 精英出现时，状态条 120 ms 淡出，精英条 160 ms 从同一位置展开；击败后反向恢复。
- 精英条只显示名称、生命和最多 2 个状态图标；技能预警仍在战场表达。
- 玩家状态最多显示 4 个正式图标，更多状态收纳为 `+N` 文本计数。
- 限时状态使用分段刻度或秒数，不同时叠加细圆环。

### 3.4 自动技能槽

- 保持 3 槽和自动施放；不得出现按压、热键、点击提示或技能按钮光泽。
- 单槽约 84×74 px；图标 56～60 px；等级位于右下，使用 `I`、`II`、`MAX`。
- 冷却从图标后方以色块上移，底部 4 px 刻度条给精确进度。
- 技能可用时仅当前槽的搪瓷节点亮 120 ms，不让三槽持续发光。
- 空槽使用正式虚线轮廓与低对比技能剪影，不使用 `＋`、Emoji 或字体图标。

### 3.5 虚拟摇杆

- 空闲时为晨湖青半透明底盘、深湖墨节点和一个搪瓷方向芯。
- 空闲透明度 0.28～0.38，触摸后升至 0.72～0.86，松手 160 ms 回落。
- 活跃时摇杆帽随触点移动，最大位移与现有操作半径一致。
- 不使用高亮攻击环、箭头文字或技能图标。

### 3.6 教学提示

- 首次提示使用窄帆布条，位于底部控件上方，不跨越玩家低噪声区。
- 文案保持“拖动左下摇杆移动”“技能会自动释放”，不添加新的操作说明。
- 完成对应动作后 240 ms 淡出；不显示通用网页 Toast。

## 4. 战斗反馈

### 4.1 敌人受击

- 35～70 ms 浅色内闪，轮廓短时加粗 1～2 px。
- 沿伤害来源方向位移 2～5 px，并生成 2～6 个属性匹配碎片。
- 伤害数字位于命中点上方，普通、暴击、治疗、格挡使用固定语义色和前缀。
- 同目标 120 ms 内的同类数字可合并，继续服从现有效果与数字预算。

### 4.2 玩家受伤

- 屏幕边缘出现 120～180 ms 珊瑚红遮罩，中心保持透明。
- 角色短促回缩，生命条同时出现缺口；镜头震动保持现有受控幅度。
- 不使用全屏红片、不改变 `Engine.time_scale`、不阻塞输入或伤害结算。

### 4.3 拾取

- 拾取物以短弧轨迹吸向玩家或对应 HUD 目标，尾迹不超过 220 ms。
- 普通经验使用晨湖青，治疗使用 Healing，磁吸/加速/爆破使用独立正式图标。
- 高价值拾取允许日照金徽章弹入一次，禁止所有拾取持续发光。

### 4.4 技能与预警

- 六项技能必须使用 ART_DIRECTION 中的轮廓锚点。
- 敌方预警至少具备颜色、形状、动画方向三重信号。
- 环境裂隙、水洼和道路不得与预警使用同色同线宽。
- 命中视觉峰值只发生在真实结算帧；不得提前爆炸或延后声音。

## 5. 三选一升级

- 保持严格三选一；整个选择面板可点击，不增加确认按钮。
- 顶部 `LV.N` 徽章高 72～88 px；其后依次排列 3 个选择面板与一个次级重抽控件。
- 单项包含：56～72 px 图标、标题、最高三行说明、目标等级/分支、品质或类型徽章。
- 禁止在选择内部再套三张指标小卡；关键数字直接进入一条对齐信息区。
- 分支二选一可共享一个组标签，但仍占两个独立选择项；第三项服从现有规划器。
- 普通、稀有、顶级通过压线层数、徽章轮廓和挂扣数量表达。
- 遮罩将战场亮度降低 45%～55%，不使用高斯玻璃模糊。
- 入场：徽章 160 ms 弹入，三个选择按 45 ms 错峰从下方上移；总时长不超过 320 ms。

## 6. 暂停界面

- 主面板宽 492 px，暖象牙帆布面与浅木上梁；不使用占满屏幕的奶油圆角卡。
- 信息顺序：暂停标题、当前构筑条、继续、音频设置、返回。
- “继续”是唯一 Accent 主按钮；重开和返回使用次级或危险轮廓。
- 构筑条直接展示当前技能与遗物，不把每项再包成独立网页卡。
- 暂停出现 180 ms，面板上移 12 px 并淡入；关闭反向 140 ms。

## 7. 胜利与失败结算

- 焦点顺序：结果标题 → 主奖励 → 本局统计 → 新发现 → 主操作。
- 胜利使用日照金徽章和暖象牙帆布；失败使用 Danger 缺口但保留同一结构。
- 主奖励只允许一个一级焦点；其他奖励以连续条或网格陈列，不与主奖励同尺寸。
- “再次远征”或“继续”作为唯一 Accent；“返回大厅”是次级操作。
- 奖励揭示依次为徽章、主体、品质节点和文字，不使用全屏金光。

## 8. 远征大厅与地图

- 首页主视觉是三个生态组成的连续远征关系，不是单一装饰性门户或后台卡片列表。
- 基准地图满铺 `540×960`：水晶火山位于上部、黄金绿洲位于中右、风铃草原位于下左，河流与道路把三个生态组织成一条连续远征路线。
- 三个目的地使用独立运行时关卡钉，中心约为 `(298,176)`、`(428,414)`、`(270,614)`；地图底图不得烘焙关卡钉、英雄、文字或导航。
- 当前英雄沿路线显示在所选目的地附近；切换目的地只更新同一地图上的英雄位置、关卡钉状态、页码和摘要，不替换整页节点树。
- 当前关卡使用日照金脉冲外环；未选关卡使用生态主色；未解锁状态保留生态色但降低饱和，并叠加正式锁形图标。
- 左上远征身份标志使用 `x8 y0 w104 h144` 的悬挂织带罗盘；不得恢复圆角方形应用图标。
- 关卡摘要固定为 `x18 y676 w330 h139` 的单块信息牌，包含关卡名、页码、推荐战力、当前战力和首通奖励；四枚 24 px 图标使用正式位图。标题与页码的结构安全右界为 `x293`，战力值固定右对齐至 `x153`，奖励名称与数量分列且右对齐至 `x293`，所有正文基线使用同一 24 px 行盒。
- “出发”是唯一 Accent 主操作，使用右下 `x340 y744 w192 h192` 的圆形罗盘帆船按钮；锁定时保留结构并显示“未解锁”。
- 底部导航为三面独立织带旗：远征、角色、图鉴，每面 `102×104`，右侧空间让给出发按钮；设置使用右上 `60×60` 搪瓷齿轮。
- 首页环境只对地图背景做统一提亮、降饱和和晨雾青色阶；角色、图标、文字和 UI 不进入该色彩处理。9:16 审阅图目标平均亮度 `0.42～0.50`、平均饱和度 `0.36～0.48`、亮度低于 `0.22` 的暗部面积不超过 18%。
- 目的地可直接点击，也可在地图区域左右滑动；不显示轮播箭头、分页圆点、后台导航栏或卡片网格。

## 9. 角色、装备与训练

- 角色始终保持当前完整 Q 版渲染；背景使用低对比生态和浅木支架，不增加纸偶关节。
- 英雄切换通过左右织带页签或角色徽章，选中后角色台和属性同时更新。
- 状态区按“战力 → 生命/伤害/移速 → 等级经验”排序，数字右对齐。
- 三个装备槽保持现有逻辑；空槽使用正式部位剪影，不使用 `＋` 字符。
- 装备背包为紧凑陈列格，品质由框结构表达；详情使用底部抽屉，不浮出多层弹窗。
- 技能训练保持现有点数、升级和重置逻辑；每项只保留图标、等级、效果与一个明确动作。

## 10. 图鉴

- 顶部分类使用织带标签与正式图标，不使用通用胶囊 Tab。
- 集合视图保持稳定网格，但共享边界和统一底板，避免“卡片海”。
- 已发现内容显示主体、名称与一个关键分类标记；未发现内容使用类别剪影和 `？？？`。
- 详情页采用左侧/上部大主体与右侧/下部信息区，根据画布比例切换。
- 分支、掉落和来源作为连续信息行，不再套独立小卡。

## 11. 音频设置与确认弹窗

- 音量行由正式图标、名称、滑杆和固定宽百分比组成；滑杆使用深湖墨轨道与晨湖青填充。
- 开关使用搪瓷拨片，不使用网页 Toggle 外观。
- 确认弹窗只处理真实破坏性或高成本行为；标题、后果和两项操作清晰分层。
- 危险确认使用 Danger 轮廓，取消保持次级；禁止两个按钮同时高亮。

## 12. 组件状态

### 12.1 面板变体

| 变体 | 用途 | 结构 |
|---|---|---|
| `CANVAS` | 常规内容 | 暖象牙、双切角、单侧织带 |
| `HUD` | 战斗信息 | 深湖墨/晨湖青结构、连续共享边界 |
| `MAP` | 路线与 Tooltip | 旧地图纸、短指向缺口 |
| `RARE` | 稀有与选中 | 双压线、搪瓷徽章、两个扣件 |
| `DANGER` | 警告与失败 | 珊瑚红内边、向内缺口 |

### 12.2 按钮状态

- `normal`：材质稳定，无持续光晕。
- `hover/focus`：标签或扣件亮度提高，轮廓不变粗。
- `pressed`：整体下沉 2 px，亮面收窄；释放后 100～140 ms 回弹。
- `disabled`：饱和度降低约 50%，仍保留文字与结构可读性。
- 同屏只允许一个 `primary` 按钮使用 Accent 填充。

### 12.3 Tooltip

- 最小宽 220 px，最大宽 360 px；内边距 16 px。
- 标题 18～20 px，正文 14～16 px，关键数字 18～22 px。
- 指向缺口宽 12～18 px，不侵入正文区，不超出 Safe Area。

## 13. 动效时间令牌

| Token | 时长 | 用途 |
|---|---:|---|
| `INSTANT` | 60～90 ms | 命中闪、节点亮起 |
| `CONTROL` | 100～160 ms | 按压、选中、页签 |
| `PANEL` | 160～240 ms | 面板、Tooltip、暂停 |
| `REVEAL` | 240～360 ms | 升级、奖励、关卡揭示 |
| `STAGE` | 360～600 ms | 阶段横幅、精英入场；只短时使用 |

- 常规 UI 使用四次以下缓动段，禁止无意义弹跳循环。
- 战斗反馈与真实时间线同步，不通过 UI 动效延迟逻辑。
- 减少动态模式下关闭装饰循环、降低位移，保留危险与命中反馈。

## 14. 文案与图标规则

- 正式图标不得使用 Emoji、Unicode 符号或字体图标替代。
- 可保留真正文本语义的 `+N`、`MAX`、罗马等级和百分比。
- 空位、锁定、声音、暂停、返回、确认、装备部位均使用正式图形节点。
- 生成图片不得包含运行时文字；名称、说明、数字和品质始终由 Godot 渲染。
- 中文标点、空格和数字格式遵循 ART_DIRECTION，不在页面自行变化。

## 15. 实现与验收

- 所有页面颜色、间距、字体、面板和按钮从共享主题/工厂取得，不直接复制 StyleBox。
- 状态图标、导航图标与操作图标从统一图形目录取得，不在页面写 Unicode。
- 3 个自动技能槽、三选一、存档 Schema、稳定 ID 和战斗数值必须保持不变。
- 四种响应式画布：540×960、540×1170、540×1200、720×960。
- 截图覆盖：首页、角色、装备、图鉴、三生态战斗、升级、暂停、胜利和失败。
- 200 ms、灰度、对比度、遮挡、触控区与视觉差异测试必须通过。
- 参考设备目标 60 FPS，低档 Android 目标稳定 30 FPS；不突破现有效果与音频并发预算。
