# 《星潮守望者》方案 D 美术方向：日光远征动画

> 状态：正式制作基准 v1.1
> 适用范围：战斗、局外界面、角色、怪物、装备、技能、特效、音频与宣传静帧  
> 上游依据：[视觉审计](./VISUAL_AUDIT.md) · [视觉方向](./VISUAL_DIRECTIONS.md)  
> 审阅参考：[战斗](./references/battle-reference.png) · [三选一](./references/reward-reference.png) · [远征地图](./references/map-reference.png)

本文档是方案 D 的视觉决策源。参考图用于表达层级、材质、氛围与尺度，不是可直接切图上线的运行时素材，也不得反向修改玩法规则。

# Visual Thesis

把幸存者式混战装进阳光下的远征动画：保留可爱鲜明的二维动漫角色，以通透自然环境、轻便远征材质和瞬时可读的赛璐璐反馈构成统一世界。

# Product Guardrails

- 游戏保持竖屏、俯视、自动攻击的 Vampire Survivors-like；玩家唯一持续操作是移动。
- 保持 3 个自动技能槽、三选一升级、现有英雄与怪物设定、稳定内容 ID、数值和存档结构。
- 不新增攻击键、技能键、闪避键、卡牌出牌区或封闭竞技场。
- 当前角色与怪物是已获认可的核心资产：不改变头身比、五官、武器比例和标志性色块。
- 画面优先服务玩家、敌人、危险、拾取物与伤害反馈的瞬时识别，其次才是环境装饰。
- 目标玩家为 8～12 岁；清新不等于低幼，危险不依赖血腥、恐怖或全屏变暗。

# Visual Keywords

- 清透赛璐璐
- 日光远征
- 自然手绘
- 轻量装备感
- 读战优先

# World Tone

世界是一条连接草原、绿洲与火山的自然远征路线。英雄和怪物像动画角色一样鲜明，地图像可进入的手绘生态，而 UI 像随队携带的帆布地图袋、桦木支架与搪瓷徽章。

平时气氛明亮、舒展、有空气感；危险出现时通过珊瑚红、收束形状、局部降噪和短促节拍收紧画面。不得用全屏黑幕、持续 Bloom 或高频粒子替代真正的信息层级。

# Shape Language

- 按钮采用横向织带、轻切角木牌或搪瓷操作牌；主按钮左右轮廓向前展开，次级按钮保持紧凑。
- 面板采用两个轻切角、单侧织带标签与不对称挂扣；同一页面最多使用两种面板母形。
- 角色和怪物保留圆润、可爱、重心稳定的动漫轮廓；敌方危险额外使用向内收束、尖角或缺口。
- 攻击类技能按功能分形：穿透和高伤偏尖锐，范围和治疗偏圆润，持续技能使用可追踪弧线或离散轨道。
- 选中、稀有和危险必须同时拥有颜色与形状信号，不能只换描边颜色。
- 布局使用 4 px 网格；允许外轮廓不对称，信息区必须严格对齐。

## 六项技能轮廓锚点

| 技能 | 64 px 识别轮廓 | 禁止混用 |
|---|---|---|
| 星芒枪 | 细长四棱枪头＋贯穿轴 | 圆形法阵、粗激光柱 |
| 日轮守卫 | 带离散节点的缺口轨道 | 完整常亮圆环 |
| 霜潮脉冲 | 单向推进的大块冰晶齿波前 | 对称圆形爆炸 |
| 烬羽连矢 | 单束或扇形羽刃 | 星芒枪的直线枪尖 |
| 陨星雨 | 纵向坠落线＋明确落点缺口 | 普通火球、装饰水洼 |
| 凤凰之心 | 双翼围合的心形负空间 | 单独爱心或医疗十字 |

# Material Language

只选择与轻便自然远征一致的材质。

- 浅色帆布：普通面板、HUD、选择卡与说明区；纹理对比不得干扰文字。
- 桦木：边梁、地图支架和按钮结构；只使用浅色哑光木纹，不做写实木屋界面。
- 搪瓷：导航徽章、品质节点、选中状态和关键图标底；高光短而克制。
- 磨砂金属：扣件、铰链和功能连接点；单屏可见面积建议不超过 4%。
- 织带与绳结：页签、路径、进度和功能分组；不得变成无意义花边。
- 旧地图纸：只用于远征路线、Tooltip 与少量说明，不主导战斗 HUD。
- 金色只解释为日照金搪瓷或小面积金属件；普通边框禁止铺金。

# Color Roles

| Role | 色值 | 使用规则 |
|---|---|---|
| Background | `#DDEFE7` | 晨雾、局外背景和地图留白；战斗地面按生态变化 |
| Surface | `#FFF6E2` | 帆布面板、奖励信息区和 Tooltip |
| Surface Alt | `#EAF4E8` | 次级面板、空槽和友方低强调区 |
| Primary Text | `#243C43` | 正文、数字、轮廓和主要结构 |
| Secondary Text | `#5C7073` | 说明、单位和次级信息；不承担关键战斗内容 |
| Primary | `#4FA7B5` | 导航、友方、选中与主结构识别 |
| Supporting | `#76B77A` | 生态、恢复、普通成长和路径 |
| Accent | `#F2B84B` | 每屏唯一主操作、升级就绪和高价值奖励 |
| Danger | `#E45B5B` | 敌方预警、玩家受伤和失败；必须配收束形状 |
| Healing | `#58B985` | 治疗与恢复；使用向上或环抱轮廓 |
| Block | `#6E91B3` | 护盾、格挡和减伤；使用闭合盾形 |
| Rare | `#6C86C8` | 稀有搪瓷内衬；必须同时出现双压线与双挂扣 |
| Legendary | `#F2B84B`＋`#FFF0B2` | 顶级徽章；三段结构和一次揭示动画共同表达 |

- 暖象牙与晨雾青负责呼吸感，深湖墨负责可读性。
- Accent 不能兼作普通装饰，Danger 不能用于无危险含义的按钮或品质。
- 新颜色进入主题前必须分配语义角色；禁止页面自行发明颜色。

# Typography Roles

| Role | 字体 | 540×960 基准字号 | 规则 |
|---|---|---:|---|
| Ceremonial Display | `assets/fonts/NotoSerifSC-UI.otf` | 32～44 px | 胜利、章节和仪式性短标题；不进入常规属性区 |
| Expedition Heading | `assets/fonts/SmileySans-Oblique.otf` | 22～36 px | 页面、关卡名、主操作；单行且不超过 8 个汉字 |
| Key Label | `assets/fonts/SmileySans-Oblique.otf` | 18～24 px | 短属性标题与强化标题；不承载段落或长说明 |
| Body | `assets/fonts/NotoSansSC-Regular.otf` | 16～18 px | 正文、按钮说明与字段名；最小功能字号 14 px |
| Numeric | Noto Sans SC，固定宽容器 | 18～30 px | 生命、时间、战力、击败、伤害和等级 |
| Card Cost | Noto Sans SC | 20～24 px | 仅为真实费用机制预留；当前禁止虚构费用 |

- 数字格式固定为 `LV.8`、`06:42`、`73 / 100`、`+18%`。
- Smiley Sans 使用发行包原始字形，不模拟额外粗体；18 px 以下回退 Noto Sans SC。
- 关键属性采用“字段名左对齐、数字固定列右对齐”，不得依靠空格拼接列。
- 文字距面板结构线至少 12 px；小图标与文字间距 8 px；文字不得与扣件、绳结或压线相交。
- 文字落在场景上时使用实色底签或局部压暗，不依赖多层描边。
- Noto Serif SC 在 24 px 以下禁用；Smiley Sans 在 18 px 以下禁用；所有小字号禁用纹理填充和镂空。
- 不把文案、数字、等级和品质烘焙进生成图片。

# Character and Monster Preservation

- 保留现有两名英雄的完整 Q 版姿势、面部、服装、武器和角色色。
- 保留四类怪物的主体设计；只统一深湖墨边缘、接地阴影、场景色阶和受击反馈。
- 英雄在 64 px 高度下通过帽型、发型、武器轴和主体色块区分；颜色是第二识别通道。
- 普通敌人不增加复杂内部纹理；精英通过徽记、体量节奏和局部危险边表达，不让全身持续发光。
- 角色脚下保留 24～36 px 低噪声区；接地阴影必须轻、短、方向一致。

# UI Border Design

- 普通面板：1.5～2 px 深湖墨外线＋低对比帆布压线，仅一侧放织带或搪瓷扣。
- 主面板：两个角切出 8～12 px 缺口，其余角近直角；禁止四角复制同一装饰。
- 选中状态：边框粗细不变，通过晨湖青标签、挂扣翻转或局部底色变化表达。
- 战斗 HUD：连续帆布信息条和共享边界，减少每个数值各自套卡。
- Tooltip：窄地图签配短指向缺口；标题、正文和关键数值分层。
- 九宫格或程序样式必须预留稳定拉伸区，装饰不得进入文字与触控安全区。

# Equipment Rarity

保持现有 `common/普通`、`rare/稀有`、`top/顶级` 三档逻辑：

| 品质 | 结构 | 轮廓与扣件 | 动画与声音 |
|---|---|---|---|
| 普通 | 单层帆布压线 | 一个圆点挂扣 | 静态，轻木或布料落位声 |
| 稀有 | 双压线＋搪瓷内衬 | 异形缺口＋两个挂扣 | 一次 180 ms 扫光，清脆双音 |
| 顶级 | 三段边框＋日照金徽章 | 非对称冠形徽记＋三个节点 | 徽章弹入一次，短促三音上行 |

品质必须同时依赖层数、徽章轮廓、扣件数量与揭示节奏；关闭颜色后仍应可区分。

# Battle Background Direction

- 地图由低频地表、中层生态簇、稀疏功能装饰和远层柔和阴影组成。
- 玩家周围约 180 px 降低 15%～20% 纹理对比与装饰密度，但不绘制可见圆形安全区。
- 风铃草原：清晨草浪、铃花簇、浅水洼和风车影；中心安静、边缘丰富。
- 黄金绿洲：暖沙丘、青绿水脉、旅行旗和耐旱植物；道路与危险区保持冷暖分离。
- 水晶火山：炭灰岩板、珊瑚红裂隙和少量蓝绿晶体；保持空气感，避免暗黑洞穴。
- 装饰以 3～5 个成簇出现，不均匀平铺，不与敌方预警同色、同形或同线宽。
- 逻辑世界边界永不作为可见竞技场边框。

# Buttons, Panels and Tooltips

- 主按钮：日照金横向织带或轻切角木牌；按下下沉 2 px，亮面收窄后回弹。
- 次级按钮：暖象牙搪瓷牌或文字加挂扣；面积与填充强度低于主按钮。
- 危险按钮：Danger 只用于真实破坏性操作，轮廓向内收束，不使用网页式红色胶囊。
- 面板：暖象牙帆布底、浅木支撑和一个身份标签；标题属于面板结构，不另套标题卡。
- Tooltip：图标、名称、作用、关键数字四段；正文最多三行，箭头不得侵入内容。
- 禁用状态：扣件转灰、饱和度降低，但文字仍满足对比度。

# Status Icon Style

- 正式图标使用两至三色赛璐璐象形、深湖墨外轮廓和明确负形。
- 主体占图标面积 65% 以上，由 2～4 个大形构成，20 px 灰度下仍可区分。
- Buff 底形向外展开，Debuff 向内收束并带缺口，Healing 环抱向上，Block 使用闭合盾形。
- 持续时间使用分段外环或底部刻度条；最后 20% 只脉冲一次主轮廓。
- 禁止 Emoji、Unicode 字符、微缩写实插画和字体图标代替正式资产。

# Combat Motion Direction

统一节奏为“蓄势色块 → 明确轨迹 → 命中单次峰值 → 少量属性粒子收尾”。

- 普通施放 100～200 ms，命中视觉保持 35～70 ms，收尾 140～280 ms。
- 不使用 `Engine.time_scale` 制造全局停顿；通过局部姿态保持、位移、描边和闪帧表达冲击。
- 敌人受击：沿来源方向短位移、轮廓加粗、一次浅色内闪和材质匹配碎片。
- 玩家受伤：珊瑚红边缘遮罩、角色短促回缩、生命条同步缺口和受控镜头震动。
- 拾取：短弧牵引、目标槽吸附和一次小徽章反馈；不改变拾取判定。
- 同屏持续循环高亮不超过 2 组；静态可读性不得依赖 Bloom。

# Audio Direction

- 音色家族：帆布摩擦、轻木敲击、搪瓷清音、短弦拨奏、自然风声和克制打击乐。
- 大厅与三个生态使用不同循环，但共享旋律材料与轻快远征节拍。
- 六项技能必须拥有不同施放主音色和命中尾音；受伤、敌人受击、拾取、升级和胜利不能复用同一主音色。
- 保留现有 AudioManager、总线、并发、优先级和音量存档；只替换或扩展声音内容。
- 禁止持续高频铃音、厚重电影低频、赛博电子扫描和所有 UI 都使用同一声响。

# Forbidden Patterns

- 禁止默认网页蓝色按钮和通用网页导航。
- 禁止无意义玻璃拟态、紫色科技渐变和 SaaS 卡片海。
- 禁止到处使用相同大圆角和均匀轻投影。
- 禁止随意增加新颜色或让所有元素统一发光。
- 禁止剪纸影戏、人偶关节、暗色剧场幕布和彩窗主导画面。
- 禁止改变现有角色和怪物比例、五官、武器与标志性色块。
- 禁止写实 3D 塑料、照片级背景和厚涂角色混入当前二维动漫资产。
- 禁止用 Emoji 代替正式游戏图标。
- 禁止生成带文字、数字、品质和按钮文案的卡牌图片。
- 禁止只换颜色、不换轮廓的技能分支、状态和装备品质。
- 禁止背景均匀铺满高频花草、石块或重复生成纹理。
- 禁止把战场改成封闭竞技场、横版道路或固定房间。

# Acceptance Criteria

- 10% 尺寸或 200 ms 暴露下，玩家、敌人、危险和拾取物四类仍可区分。
- 灰度下，两名英雄、四类敌人与六项技能主轮廓不混淆。
- 战斗第一眼顺序为玩家与附近危险、敌群、拾取物、HUD、环境装饰。
- 正文不低于 14 px；关键触控区不小于 48×48 px。
- 常态战斗不透明 HUD 面积不超过 15%；精英阶段不超过 20%。
- 任一页面只有一个 Accent 主操作；稀有与顶级不只依赖色相。
- 3 秒内至少 80% 测试者判断玩法为 Vampire Survivors-like。
- “角色仍像当前游戏”“可读性”“清新动漫一致性”平均不低于 4/5。
- “网页模板感”“明显 AI 拼贴感”平均不高于 2/5。
